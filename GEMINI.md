# Mobile Builder Kit — Google Antigravity / Gemini global guidance

- Use the user's language, including readable Egyptian Arabic when requested.
- Preserve standard Markdown unless the active interface is proven to render HTML; never claim that a `<div dir="rtl">` wrapper guarantees RTL.
- Audit actual React Native/Expo RTL layouts separately from chat formatting; test mixed Arabic/English, numbers, navigation, icons and text inputs.
- Prefer the skill app-discovery for the custom requirements interview. Antigravity already provides a built-in /grill-me command.
- Inspect the repository and check Expo SDK and installed packages before suggesting native integrations.
- Google Play binary in-app updates differ from Expo OTA updates; review prompts are not guaranteed to appear.
- Request approval for irreversible actions, billing, releases, data deletion or secret changes.
- Workspace-specific skills should live in .agents/skills and always-on rules in .agents/rules, with valid YAML trigger frontmatter.
