# App Discovery — original, focused requirements interview

1. Inspect project notes and code before asking questions; do not repeat answered decisions.
2. Ask exactly one important question per turn with a concise recommended default.
3. Cover audience, core workflow, offline/auth/data, privacy, risks, and monetization as necessary.
4. Stop when implementation-critical unknowns are resolved, not when an arbitrary quota of questions is reached.
5. Output an MVP brief, excluded features, acceptance tests and a first safe step.
6. Let the user say "skip", "choose default" or "stop questions".

The older `grill-me` skill remains in the repository as a compatibility alias; Antigravity already has a native `/grill-me` command, so this unique skill name should be used instead.
